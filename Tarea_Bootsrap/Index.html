Sobre el proyecto

Esta página fue creada como parte de una actividad académica para demostrar el uso de HTML5, CSS y Bootstrap.

Diseño Responsivo

El contenido se adapta automáticamente a diferentes tamaños de pantalla utilizando las clases responsive de Bootstrap.

Utilización de una estructura organizada y semántica de HTML5.

CSS

Aplicación de estilos personalizados, selectores y modelo de caja.

Bootstrap

Uso de componentes y clases responsive para adaptar el contenido.
